# Code of conduct

Keep issues, reviews and discussions focused on the work. Be specific, assume
questions are asked in good faith and make criticism useful to the person
receiving it. Disagreement is welcome; harassment, threats, discrimination and
personal attacks are not.

Respect privacy. Do not publish someone else's personal information, credentials
or private project content. Use demonstration data in examples and screenshots.

Maintainers may edit or remove inappropriate content, close discussions or
restrict participation. Report a conduct problem to the repository maintainer.
If a private channel is needed, ask for one without posting personal or sensitive
details publicly.
