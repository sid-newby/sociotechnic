# Run console

Mode: Operate. The developer supervising coding agents opens the selected run
to learn whether it needs them, what it is doing now, and what it has cost,
then reads a document or a record and acts. Desktop leads; narrow stays usable.

Audience and job: the owner, often while a run is working. Proof: recorded
dispatches, records, checks and usage bound to commits. Constraints: loopback
server, self-only CSP, local assets, the engine owns every transition.

## Direction contract

THESIS: One dashboard shows what the engine is doing and what it costs, and
discloses why only on click. It refuses the tabbed evidence dump and the stage
strip.

OWN-WORLD: shadcn's neutral dark as the default: near-black ground, cards one
step lighter, 1px borders at ten percent white, 10px radius, Geist, 16px body.
Role hues come from the five chart tokens; status is an outline pill with an
icon; the one primary action is near-white. Presets switch the whole world
without touching the composition.

STORY: The developer sees the inbox count, lands on the run, reads one
sentence in the decision bar, scans four cards, watches the burn chart, opens a
sheet for the plan or the record, and acts from the bar.

FIRST VIEWPORT: collapsible sidebar on the left (wordmark, New run, nav, Inbox
counts); header with breadcrumb and status; the decision bar when the run
waits with the primary action at its right; four section cards; the token burn
chart with its range toggle; the tabs and table below the fold. Sheets slide
from the right.

FORM: the shadcn dashboard-01 block, played straight. Pinned by the owner
after the surface round (seed 262fc3f5) dealt Memo and Board, Cockpit and
Spine with Departures as challenger; all four were built as samples and
declined. Not from the ranked list.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
